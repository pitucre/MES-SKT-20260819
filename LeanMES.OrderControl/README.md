# LeanMES 注塑机订单数量控制系统 使用说明

## 一、系统概述

本系统用于监控注塑机的生产数量，当生产数量达到订单目标数量时，自动发送停止命令给注塑机，实现订单数量的精确控制。

### 支持设备

| 品牌 | 通信协议 | 说明 |
|------|---------|------|
| 恩格尔 (Engel) | EUROMAP 63 | 通过文件监控和REQ命令控制 |
| 海天 (Haitian) | OPC UA | 通过OPC UA协议读写数据 |
| 德马格 (Demag) | OPC UA | 通过OPC UA协议读写数据 |

## 三、安装部署步骤

### 3.1 数据库配置

1. 打开 SQL Server Management Studio
2. 连接到目标数据库服务器
3. 执行数据库脚本：
   ```sql
   -- 执行创建表和存储过程的脚本
   :r E:\source\MES\SKT\20260819\LeanMES.OrderControl\Database\CreateOrderControlTables.sql
   ```

### 3.2 修改配置文件

编辑 `App.config` 文件，修改数据库连接字符串：

```xml
<appSettings>
    <add key="MESConnString" value="server=你的服务器;uid=用户名;pwd=密码;database=LeanMes" />
    <add key="OrderControlInterval" value="30" />  <!-- 检查间隔(秒) -->
</appSettings>
```

### 3.3 编译项目

1. 用 Visual Studio 2019/2022 打开 `LeanMES.OrderControl.sln`
2. 还原NuGet包
3. 生成解决方案 (Ctrl+Shift+B)

### 3.4 运行程序

```bash
# 直接运行
LeanMES.OrderControl.exe

# 或作为Windows服务运行 (需要额外配置)
```

## 四、使用方法

### 4.1 创建订单

在数据库中插入订单：

```sql
INSERT INTO OrderControl 
(MachineCode, MachineType, OrderNo, PartNumber, PartName, OrderQuantity, Status, ControlEnabled)
VALUES 
('212352', 'Engel', 'WO20260916001', '6128.26.6.17', '外壳', 150000, 0, 1);
```

参数说明：
- `MachineCode`: 机台编号
- `MachineType`: 设备类型 (Engel/Haitian/Demag)
- `OrderNo`: 工单号
- `OrderQuantity`: 订单数量
- `Status`: 0=待生产, 1=生产中
- `ControlEnabled`: 1=启用自动控制

### 4.2 启动监控

启动程序后，系统会自动：

1. **每30秒检查一次**所有活跃订单
2. **读取机台当前生产数量**
3. **比较是否达到目标数量**
4. **达到目标后发送停止命令**

### 4.3 查看日志

日志文件保存在程序目录下的 `Logs` 文件夹中：

```
Logs/
├── 2026-09-17.log
├── 2026-09-16.log
└── ...
```

### 4.4 查看控制记录

```sql
-- 查看订单控制日志
SELECT * 
FROM OrderControlLog 
WHERE MachineCode = '212352'
ORDER BY CreatedDate DESC
```

## 七、控制流程

```
┌─────────────────────────────────────────────────────────────────┐
│  1. 定时任务触发 (每30秒)                                        │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  2. 查询数据库获取活跃订单                                        │
│     SELECT * FROM OrderControl WHERE Status IN (0,1)            │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  3. 读取机台当前生产数量                                          │
│     - 恩格尔: 读取MESData.dat文件                                │
│     - 海天/德马格: 读取OPC UA节点                                │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  4. 比较数量并判断                                               │
│     IF 当前数量 >= 订单数量 THEN                                 │
│         发送停止命令                                             │
│         更新订单状态为"已完成"                                    │
│     ELSE                                                        │
│         更新已完成数量                                           │
│     END IF                                                      │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  5. 记录操作日志                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 八、常见问题

### Q1: 程序无法连接数据库
**解决方案:**
1. 检查 `App.config` 中的数据库连接字符串
2. 确认数据库服务器是否可达
3. 确认数据库用户名和密码是否正确

### Q2: 无法读取恩格尔机台数据
**解决方案:**
1. 检查 `C:\Engel\Euromap63\System\Access\MACHINES\{机台编号}\E63_JOBS\MESData.dat` 文件是否存在
2. 确认机台编号是否正确
3. 检查文件是否有读取权限

### Q3: OPC UA连接失败
**解决方案:**
1. 检查设备IP和端口是否正确
2. 确认网络是否连通
3. 检查设备OPC UA服务是否正常运行

### Q4: 停止命令未执行
**解决方案:**
1. 检查日志文件查看命令是否发送成功
2. 确认机台是否在线
3. 检查EUROMAP 63 REQ文件是否写入成功

## 九、注意事项

1. **安全提醒**: 自动停止功能请在确认安全的情况下启用
2. **备份建议**: 修改数据库前请先备份
3. **权限要求**: 需要对数据库有读写权限
4. **网络要求**: 机台与服务器之间网络需要连通
5. **日志清理**: 系统会自动清理过期日志，默认保留30天
