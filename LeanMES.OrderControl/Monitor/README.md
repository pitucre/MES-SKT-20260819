# 注塑机连接状态监控页面

## 功能说明

实时监控32台注塑机的连接状态，包括：
- 设备在线/离线/待机状态
- 连接类型（OPC UA / MQTT / 无连接）
- IP地址和端口信息
- 运行状态（正常/调试/故障/报警）

## 文件结构

```
Monitor/
├── index.html              # 监控页面主文件
└── README.md               # 本说明文档
```

## 页面功能

### 1. 统计卡片
- **设备总数**: 显示所有注塑机数量
- **运行中**: 状态为"运行"的设备数量
- **待机中**: 状态为"待机"的设备数量
- **停用/维护**: 状态为"停用"或"维护"的设备数量

### 2. 过滤按钮
- **全部**: 显示所有设备
- **运行中**: 只显示运行状态的设备
- **待机中**: 只显示待机状态的设备
- **停用/维护**: 只显示停用或维护状态的设备

### 3. 设备卡片
每个设备卡片显示：
- 设备名称和状态标签
- 设备编号
- 连接类型（OPC UA / MQTT / 无连接）
- IP地址和端口
- 运行状态
- 最后更新时间

### 4. 刷新按钮
右下角的刷新按钮可手动刷新数据

## API接口

如果需要通过API获取数据，可以使用以下接口：

### 获取所有设备状态
```
GET /api/MachineStatus/GetAll
```

### 获取统计信息
```
GET /api/MachineStatus/GetStatistics
```

### 根据状态筛选
```
GET /api/MachineStatus/GetByStatus/{status}
```
status可选值: online, standby, offline

## 配置说明

### 数据库连接
在 `App.config` 中配置数据库连接字符串：
```xml

    <add name="MESConnString" connectionString="server=172.16.5.179;uid=sa;pwd=SAsa123;database=PROD_TEST_MES" providerName="System.Data.SqlClient"/>
</connectionStrings>
```

### 静态数据
如果API不可用，页面会自动使用静态数据进行展示。

## 注意事项

1. 页面使用响应式设计，支持PC和移动端访问
2. 数据默认每30秒自动刷新
3. 点击刷新按钮可立即刷新数据
4. 过滤器支持多条件筛选
