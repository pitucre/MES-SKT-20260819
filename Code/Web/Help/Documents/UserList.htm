用户列表
字段描述
字段名 描述
登录名用来登录系统的账号
工号员工工号
中文名中文名称
英文名英文名称
状态有两种状态：正常，锁定
功能描述
显示系统所有的用户，可执行编辑、新增、删除操作
搜索用户
1.输入登录名、工号、中文名、英文名等关键字；
2.点击搜索按钮后列表显示结果。
新增用户
增加新的用户
编辑用户
编辑存在的用户
删除用户
1.在列表中选中记录后单击删除按钮；
2.在弹出的对话框中选择Ok或Cancel。
角色分配
给指定用户分配角色
岗位认证授权
给指定用户授权岗位认证资格
重置密码
1.在列表中选中记录后单击重置密码按钮；
2.在弹出的对话框中选择Ok或Cancel。
解锁
1.在列表中选中记录后单击解锁按钮；
2.在弹出的对话框中选择Ok或Cancel。
注销
1.在列表中选中记录后单击注销按钮；
2.在弹出的对话框中选择Ok或Cancel。
