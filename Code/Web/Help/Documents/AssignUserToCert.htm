授权用户岗位认证
字段描述
字段名 描述
登录名用来登录系统的账号，系统自动带出
工号员工工号，系统自动带出
中文名中文名称，系统自动带出
英文名英文名称，系统自动带出
岗位授权日期岗位授权的开始日期，默认为当前日期
过期日期岗位过期日期，默认为授权日期加一年
认证名称岗位认证的名称
描述岗位认证的描述
功能描述
对用户进行岗位认证的分配
分配移除岗位认证
1.选择主页中相应的用户记录后单击工具栏中的岗位认证授权按钮；
2.在左边区域中搜索出需要授权的岗位认证并选中；
3.修改授权日期和过期日期；
4.单击"右移"按钮，完成系统对该用户的岗位认证授权；
5.单击"左移"按钮，完成系统对用户岗位认证授权的移除
