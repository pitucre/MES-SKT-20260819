功能描述
显示所有的掩码组，可执行编辑、新增、删除操作
搜索产品
1.输入产品名称关键字；
2.点击搜索按钮后列表显示结果。
搜索产品结构
1.点击按钮；
2.弹出选择窗体，选择需要数据；
3.点击确定。
新增产品结构
1.点击新建按钮；
2.选择增加到产品结构产品，点击+按钮；
3.增加新的产品结构。
编辑产品结构
1.点击编辑图标按钮；
2.编辑产品结构信息；
3.保存更改。
删除产品结构
1.在列表中产品结构支点；
2.点击工具栏中的删除按钮：
3.在弹出的对话框中选择Ok或Cancel。
