周转工具种类
字段描述
字段名 描述
周转工具种类周转工具类别
描述周转工具类别说明
创建时间周转类别的创建时间
功能描述
显示系统所有的周转工具类别，可执行编辑、新增、删除操作
搜索周转工具种类
1.输入周转工具种类关键字；
2.点击搜索按钮后列表显示结果。
新增周转工具种类
1.主页中直接单击工具栏上的新增按钮，弹出新窗口；
2.在弹出的新窗口中输入相关信息；
3.最后单击保存按钮。
编辑周转工具种类
1.主页中选中记录后单击工具栏上的编辑按钮，弹出新窗口；
2.在弹出的新窗口中输入要修改的相关信息；
3.最后单击保存按钮。
删除周转工具种类
1.在列表中选中记录后单击删除按钮；
2.在弹出的对话框中选择Ok或Cancel。
