字段描述
字段名 描述
路由名称路由的名称
描述对路由的说明
状态Releasable:释放状态，为可用状态；
Frozen: 冻结状态，但不能更改。为可用状态；
Obsolete:报废状态，为不可用状态；
Hold: 暂停状态，为不可用状态；
New:新添加的状态，为不可用状态，需要转化相关可用状态方可使用；
Hold Consec NC：系统保留状态，为不可用状态；
Hold SPC Viol：系统保留状态，为不可用状态；
Hold SPC Warn:系统保留状态，为不可用状态；
Hold Yield Rate:系统保留状态，为不可用状态
功能描述
修改存在路由名称，绑定产品
保存
1.主页中选中记录后单击编辑按钮；
2.修改相关路由信息；
3.单击保存
绑定产品
1.切换至绑定产品选项卡，右上角单击新增链接；
2.单击按钮选择系统中的产品和具体版本；
3.也可对绑定产品进行修改和删除；
4.单击保存
