路由设计
字段描述
字段名 描述
工位类型列出系统存在的所有工位类型
功能描述
设计修改路由,绑定产品
载入
单击载入按钮后选择系统中的路由名称，系统将显示该路由信息
绑定产品
1.路由装载后单击绑定产品按钮进入绑定页面，右上角单击新增链接；
2.单击按钮选择系统中的产品和具体版本；
3.也可对绑定产品进行修改和删除；
4.单击保存
清空屏幕
对右边设计框中的路由内容清空
保存设计
1.创建好新的路由名称后单击载入，选择所创建的路由名称；
2.在工位类型中单击所要使用的类型；
3.直接选择工位或通过搜索关键字找到具体的工位名称，拖入右边的设计区域；
4.把所有要用到的工位拖入后，针对实际工艺流程对每两个工位，单击连接点按钮进行连接，设计区域中双击连接线可选择流向的条件是Pass还是Fail；
5.为使界面美观，可单击布局按钮，系统将自动排列好各工位；
6.单击保存设计
