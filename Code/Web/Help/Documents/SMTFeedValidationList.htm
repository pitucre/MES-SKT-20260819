功能描述
设置线别，上料，续料操作
线别设置
1.进入线别设置界面，选择线别,通过线别自动带出料站表信息;
2.选择其中一条记录状态为活动的记录;
3.点击保存即可。
开拉
1.进入上料验证界面，选择对应的工单;
2.选择对应的线别自动带出对应的料站表上料信息;
3.扫描插槽号，GRN,FeedSN(如有飞达号需扫描飞达号)
4.当该料站表的物料全部上料完成之后，点击开拉。
停拉
1.进入上料验证界面，选择对应的工单;
2.选择对应的线别自动带出对应的料站表信息，该料站表处于已开拉状态;
3.如遇到异常情况，产线已停线，点击停拉即可。
续料
1.选择需要续料对应的工单;
2.输入工单中对应的oldGRN;
3.输入物料跟oldGRN相同的NewGRN;
4.点击续料。
