功能描述
显示系统所有的工单，可执行编辑、新增、删除操作
搜索工单
1.输入工单号或产品名称关键字；
2.点击搜索按钮后列表显示结果。
新增工单
1.主页中单击新增按钮；
2.输入工单相关的信息；
3.点击保存
编辑工单
1.主页中选中记录后单击编辑按钮；
2.修改工单相关的信息；
3.点击保存
删除工单
1.在列表中选中记录后单击删除按钮；
2.在弹出的对话框中选择Ok或Cancel。
