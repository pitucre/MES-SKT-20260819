-- 应返回 3 个 HAS_STATUS2
SELECT o.name,
  CASE WHEN m.definition LIKE '%B.Status = 2%' THEN 'HAS_STATUS2' ELSE 'NO_STATUS2' END
FROM sys.sql_modules m
INNER JOIN sys.objects o ON o.object_id = m.object_id
WHERE o.name IN ('uspBoardCountPickListMaterial','uspBoardCountPickListInjectionMaterial');

-- 应返回 2 个 HAS_STATUS_MSG
SELECT o.name,
  CASE WHEN m.definition LIKE '%状态非在线%' THEN 'HAS_STATUS_MSG' ELSE 'NO' END

## Bug ②：GRN 状态异常（调拨后上料记录未清理）

**根因**：调拨入库只改 Status/库位，不清理上料关系；扣料 SP 只看 BalanceQty>0 + 上料记录，不校验 Status。

### 修复内容

1. **方案A**：`uspSaveTransferIn` 增加 3.1 节，调拨入库时自动清理上料关系
2. **方案B**：扣料 SP 增加 `AND B.Status = 2` 校验

### 测试场景 2.1：调拨入库清理上料记录

# **测试数据**：调拨单 TEST20261010001（TransfersId=5302）

- 明细1：0602-00034，GRN251224000065（注塑上料，Status=0）
- 明细2：0302-00045，GRN260107000057（注塑上料，Status=0）

#### 步骤

1. 打开 PDA 调拨入库页面（TransferIn.aspx）
2. 扫描调拨单号：`TEST20261010001`
3. 扫描库位条码（101一楼立体仓库的库位）
4. 扫描 GRN：`GRN251224000065`
5. 点击"确认调拨"

#### 预期结果

- **弹出确认框**：显示"以下GRN存在上料记录...调拨入库将自动删除这些上料记录，是否继续？"
- 点"确定" → 调拨成功，上料记录被删除
- 点"取消" → 中止调拨

#### 验证 SQL

```sql
-- 调拨后，该 GRN 的上料记录应为空
SELECT * FROM Prod_InjectionLoadingMaterial WHERE MaterialUnitId = 572697;
-- 应返回 0 行
```

### 测试场景 2.2：无上料记录直接调拨

#### 步骤

1. 同上，但扫描一个**没有上料记录**的 GRN
2. 点击"确认调拨"

#### 预期结果

- 不弹出上料记录确认框
- 直接弹出"是否确认调拨?"

## Bug ③：注塑扣料拦截（Status=2 校验）

**需求**：扣料时只允许扣 Status=2（在线上）的物料。

### 测试场景 3.1：有 Status=2 物料 → 正常扣料

#### 准备

```sql
-- 确保料桶003有 Status=2 的物料
UPDATE Prod_MaterialUnit SET Status = 2
WHERE MaterialUnitId IN (370464, 598918, 596190);
```

#### 步骤

1. 打开注塑机看板（32号注塑机）
2. 选择工单 S260110B032-1
3. 点击"良品标签打印"
4. 输入打印数量，点击打印

#### 预期结果

- 扣料成功，正常打印标签
- 扣的是 Status=2 的物料（MaterialUnitId 370464/598918/596190）

### 测试场景 3.2：无 Status=2 物料 → 提示状态不对

#### 准备

```sql
-- 把料桶003所有物料改成 Status=1（制造无可扣状态）
UPDATE Prod_MaterialUnit SET Status = 1
WHERE MaterialUnitId IN (370464, 598918, 596190);
```

#### 步骤

1. 同上，点击"良品标签打印"

#### 预期结果

**新提示**（区分了状态问题）：

```
物料编码[0602-00034]物料名称[xxx]有余量[213.25]但状态非在线(状态:1)，无法扣料，请检查物料状态!
```

**注意**：如果料桶上完全没有物料（BalanceQty=0），则提示原有格式：

```
没有可扣数物料,请及时续料!
```

### 测试场景 3.3：部分物料 Status=2 部分不是 → 只扣正确的

#### 准备

```sql
-- 只保留一个 Status=2
UPDATE Prod_MaterialUnit SET Status = 2 WHERE MaterialUnitId = 370464;

```

#### 步骤

1. 点击"良品标签打印"

#### 预期结果
